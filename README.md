# GTA RP Daily — Инструкция по запуску

## Требования
- Rust (установлен через rustup.rs)
- Node.js LTS
- Microsoft C++ Build Tools

---

## Первый запуск (только один раз)

1. Распакуй архив в любую удобную папку, например `C:\Projects\gta-rp-daily`

2. Открой папку проекта в проводнике, в адресной строке напиши `cmd` и нажми Enter

3. Установи npm-зависимости:
   ```
   npm install
   ```

4. Запусти приложение в режиме разработки:
   ```
   npx tauri dev
   ```
   
   **Первый раз компиляция займёт 3–7 минут** — Rust скачивает и компилирует зависимости.
   Последующие запуски будут быстрыми (5–15 секунд).

---

## Обычный запуск

После первого раза просто открывай папку проекта через cmd и пиши:
```
npx tauri dev
```

---

## Данные (прогресс)

Прогресс сохраняется автоматически в:
```
C:\Users\{твой_юзер}\AppData\Roaming\com.gtarp.daily\state.json
```

При сбросе (кнопка ↺) файл очищается, но не удаляется.
