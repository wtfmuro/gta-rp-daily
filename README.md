# 🎮 GTA RP Daily

Трекер ежедневных заданий для GTA 5 RP сервера с подсчётом Bonus Points.

---

## ✨ Возможности

- Список всех ежедневных заданий разбитый по категориям
- Подсчёт заработанных BP с учётом множителей
- Множители **VIP** и **Серверный ×2** (включаются в один клик)
- Счётчики для заданий с повторениями (например, Кинотеатр 0/5)
- Подсказки по каждому заданию — нажми на задание чтобы увидеть
- Настройка порядка заданий через drag & drop
- Прогресс сохраняется автоматически при закрытии
- Кнопка сброса для начала нового дня

---

## 📥 Установка

1. Перейди в раздел [Releases](../../releases)
2. Скачай файл `gta-rp-daily.exe`
3. Запусти — установка не требуется

> Приложение портативное. Можно положить в любую папку и запускать напрямую.

---

## 💾 Где хранится прогресс

Прогресс сохраняется автоматически в:
```
C:\Users\{имя}\AppData\Roaming\com.gtarp.daily\state.json
```
