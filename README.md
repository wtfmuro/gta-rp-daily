# GTA RP Daily

> Трекер ежедневных заданий и таймеров для GTA 5 RP

---

## Возможности

### Farm BP

- 5 категорий заданий — **Лёгкие**, **Средние**, **Совместные**, **Не хочется**, **Фракционные**
- Подсчёт заработанных BP с учётом множителей **VIP** и **Серверный ×2**
- Счётчики для заданий с повторениями (например, `0/5`, `0/25`)
- Сворачивание категорий — скрывай ненужные разделы
- Настройка порядка заданий через drag & drop
- Прогресс сохраняется автоматически рядом с `.exe`
- Кнопка сброса для начала нового дня

### Таймеры

- 16 готовых пресетов: Организация, Почта, Автоугон, Сутенерка, Контрабанда и другие
- Добавление собственных таймеров с произвольной длительностью
- Редактирование и удаление кастомных таймеров
- Несколько таймеров работают одновременно
- Звуковой сигнал и уведомление по завершении
- Drag & drop для изменения порядка
- Drift-free отсчёт — точное время даже при свёрнутом окне

---

## Установка

1. Перейди в раздел [Releases](../../releases)
2. Скачай `gta-rp-daily.exe`
3. Положи в удобную папку и запусти — установка не требуется

> Прогресс и таймеры сохраняются автоматически в `state.json` и `timers.json` рядом с `.exe`
