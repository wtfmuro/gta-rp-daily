# GTA RP Daily — Farm BP

> Трекер ежедневных заданий для GTA 5 RP с подсчётом Bonus Points

---

## Возможности

- 5 категорий заданий — **Лёгкие**, **Средние**, **Совместные**, **Не хочется**, **Фракционные**
- Подсчёт заработанных BP с учётом множителей **VIP** и **Серверный ×2**
- Счётчики для заданий с повторениями (например, `0/5`, `0/25`)
- Сворачивание категорий — скрывай ненужные разделы
- Настройка порядка заданий через drag & drop
- Прогресс сохраняется автоматически рядом с `.exe`
- Кнопка сброса для начала нового дня

---

## Установка

1. Перейди в раздел [Releases](../../releases)
2. Скачай `gta-rp-daily.exe`
3. Положи в удобную папку и запусти — установка не требуется

> Прогресс сохраняется автоматически в `state.json` рядом с `.exe`
